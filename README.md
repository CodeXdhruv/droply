# Droply - Send Files Easily

Droply lets you send files directly from one device to another using a simple 6-character code. No need to sign up, use an email, or create an account.

## How to use it

**To Send a File:**
1. Open the Droply browser tool (the little icon in your browser).
2. Pick the file you want to send.
3. You will get a simple code and a picture (QR code).
4. Give that code or show the picture to the person receiving the file.

**To Receive a File:**
1. Go to the link provided by the sender or scan the picture with your phone.
2. The file will start downloading automatically once the sender shares it.

## Why use Droply?

✅ **No Sign Up Required** - Just start sharing. You don't need to give us your name or email.
✅ **Super Fast** - Files go straight from your computer to the other person's device. 
✅ **Private & Secure** - Your files are never stored on any server. They travel directly between devices.
✅ **Share with Many** - You can send the same file to several people at once using the same code.
✅ **Easy Sharing** - Use a simple code or scan a picture to connect instantly.

## How to Install the Browser Tool

1. Go to the [Releases](#releases) section below.
2. Download the ZIP file.
3. Unzip the file on your computer.
4. Open your browser's extensions page (usually found in settings).
5. Turn on "Developer mode."
6. Click "Load unpacked" and select the folder you just unzipped.
7. You're all set! You'll see the Droply icon at the top of your browser.

## Common Questions

**What files can I send?**
You can send almost anything! Photos, videos, documents, and folders.

**Does it work on phones?**
Yes! You can scan the code with your phone to receive files easily.

**Is there a file size limit?**
Currently, you can send files up to 100MB.

**What if it's slow?**
- Make sure you have a good internet connection.
- Try moving closer to your Wi-Fi router.
- Refresh the page and try again.
